# 素材、配置与运行

## 环境与首次运行

Node.js 22，使用根目录 `npm ci`。根目录 workspace 会安装历史 Three.js 实验的依赖，因此干净检出后的类型检查不依赖开发者曾经手工安装过的子目录包。基础检查：

```sh
npm ci
npm test
npm run lint
npm run build
npm run check:assets
npm run render:poster
```

基础 `AnchorPromo` 使用仓库内的公开演示内容。生产研究使用用户自备素材，缺少素材时不会出现在主 Studio 列表中；独立 `studies` 入口仍可启动，但必须先配置输入。不得把 `npm run build` 成功理解为所有生产视频已渲染验证。

Blender 脚本是在本地 Blender 5.2.2 环境制作的，包含 EEVEE、Cycles 和序列编辑器 API；其他 Blender 版本需要单独核验。macOS 默认可执行文件路径保留为平台默认值；其他系统默认使用 PATH 内的 `blender`，可通过 `BLENDER_BIN` 指定。中文排版优先使用 PingFang SC / 黑体，其他系统应安装对应中文字体，并重新检查换行和裁切。

## 输入素材

生产用真实素材放在 `public/local-assets/2026-09-30/real/`。这些文件不提交到 Git：

| 文件 | 用途 | 原制作尺寸或规格 |
| --- | --- | --- |
| `iphone-home.png` | 移动端总览 | 1206×2622 |
| `mac-home.png` | 工作区总览与接续 | 横向页面；原版 2160×1376 |
| `mac-workflow.mp4` | 真实选择操作及返回工作区 | 原版 1440×918，30 fps，8.5 秒 |
| `mac-first.png`、`mac-closing.png` | 录屏首尾的静态桥接帧 | 渲染片头脚本会从录屏派生 |
| `card-0.png`～`card-3.png` | 真实任务卡片裁切 | 保持原页面比例 |
| `page-header.png`、`decision-callout.png` | 原动效版本的页面局部 | 真实截图裁切 |

原路径中的日期是兼容已有动画的素材槽位，不要求新截图仍在该日期采集。替换素材应保留文件名和宽高比；更换不同长宽比后要修改构图与抽帧复核。录屏短于 8.5 秒时，历史脚本的 8.466666 秒末帧采样也要调整。

```sh
npm run check:assets -- native
npm run check:assets -- value
npm run check:assets -- hero
```

`native` 检查主片头/整片素材，`value` 检查平面中段所需子集，`hero` 检查已编码的 Blender 视频；它们只检查文件存在，不证明视频可解码。基础公开演示可不配置这些素材。

Blender 片头另需 `public/local-assets/2026-10-01/hero/hero-A.mp4`、`hero-B.mp4`、`hero-C.mp4` 及末帧图片，由 `encode-heroes.mjs` 生成。标志轮廓已随源码提供，不能把 `draft-*.mp4` 预览误作最终三维动画。

## 本地配置

| 环境变量 | 用途 |
| --- | --- |
| `ANCHOR_DELIVERABLES_ROOT` | 所有历史输出子目录的共同根目录；默认仓库同级 `Deliverables` |
| `ANCHOR_IDENTITY_FILE` | 片尾文案 JSON；示例为 `examples/ending-info.example.json` |
| `ANCHOR_APP_ICON` | 自备完整 App 图标；未指定时使用本地素材图标或公开品牌标志作为占位 |
| `BLENDER_BIN` | 海洋渲染脚本启动 Blender 的路径 |
| `ANCHOR_EDIT_FPS` | 平面价值总结的工程帧率；支持 25、30、60 |

将示例文案复制到被 Git 忽略的 `local-config/` 后填写。没有本地文案文件时采用通用品牌名，学校和组别留空。已有旧交付目录中的 `original-ending-info.json` 继续作为兼容回退。只有明确提供 `sourceVideo` 字段时，光影片尾脚本才读取参考片并生成左右对比；该字段必须指向你有权使用的本地视频。

```sh
mkdir -p local-config
cp examples/ending-info.example.json local-config/ending-info.json
ANCHOR_IDENTITY_FILE=local-config/ending-info.json npm run render:ending:ae
ANCHOR_DELIVERABLES_ROOT=./out/production npm run render:value
```

Node 与 Blender 阶段必须使用相同的 `ANCHOR_DELIVERABLES_ROOT`。`render-hero-rebuild.mjs --out=...` 是单步输出覆盖，后续拼接仍需要对应目录；批量流程更适合使用共同环境变量。

## 验证与公开范围

1. 先 `--review-only` 检查关键帧，再做整段渲染；该参数适用于支持它的 Remotion 导出脚本，不能直接传给 Blender。
2. 检查标题停留时间、UI 裁切、转场前后帧、最后一帧，以及字号在实际分辨率下是否可读。
3. 使用导出校验检查帧数、时长、分辨率、帧率和音轨，并解码完整 MP4。抽帧必须从最终编码文件中进行。
4. 基础 `npm test` / lint / bundle 检查不能替代带素材的渲染检查；公开 CI 不拥有私人素材，也不运行全量 Blender 渲染。

本仓库同步源码、中文注释、通用配置与经验。聊天截图、个人/比赛信息、真实原始录屏、音频、生成视频、`.blend`、帧序列和构建缓存不随本次源码同步。Remotion 的 bundle 会复制 public 素材，生产构建目录也应保持本地，不直接当作公开网站发布。
