# 动画脚本与效果目录

本目录对应仓库现有源码及本地历史交付。相同字母在不同系列里代表不同方案，选用时请同时查看系列名。默认片段均无声；画面中的标题属于设计文字，不是逐句旁白字幕。

## 如何选

- 产品介绍需要与真实界面统一：优先选择「中段平面 A/B/C」或「短片头 A/B」。
- 先强调品牌，再展示产品：选择 20 秒品牌片头 A/B/D。
- 明确需要实体材质、景深、三维运镜：选择 Blender 片头或三维片尾。
- 作品信息与品牌收束：选择 14 秒光影片尾；它含透视、分层和立体图标视觉，不属于严格平面风格。
- 「AE 风格」描述遮罩、缓动、扫光等效果。这些源码由 Remotion 实现，不是 After Effects 的 `.aep` 工程，也不依赖 UE。

### 生成命令

```sh
# 短片头与 26 秒整片；所有素材配置见「素材与运行」。
node scripts/render-motion.mjs --only=A --review-only
node scripts/render-motion.mjs
node scripts/assemble-motion.mjs

# 四个 20 秒品牌版本；可用 --only=B 单独选择。
node scripts/render-brand.mjs --review-only
npm run render:brand:delivery

# 三维品牌：先渲染三套真实几何动画，再编码、合成。
blender --background --python scripts/blender-hero.py -- --variant A
blender --background --python scripts/blender-hero.py -- --variant B
blender --background --python scripts/blender-hero.py -- --variant C
npm run render:hero:delivery
```

`blender-queue.py` 是历史续渲辅助脚本，只运行 B、C，不会替你渲染 A。首次构建请使用上面的完整顺序。`--review` 仅生成检查帧；`--frames 1,80,150` 用于指定原始帧抽样。品牌标志轮廓保存在 `public/brand/logo-contours.json`，为公开品牌图片的派生几何。

## 片尾及投锚组合

| 方案 | 参数 | 效果、用途与限制 | 源码 |
| --- | --- | --- | --- |
| 三维片尾研究 | 12 秒 / 30，1280×720 | 前 6 秒实体设备拉远、侧移并穿过环形结构，后半段信息卡与品牌落版；历史镜头研究 | `studies/ending-3d/scene.py` + `Entry.tsx` + `render.mjs` |
| 光影片尾 | 14 秒 / 60，1920×1080 | 青绿色光场、页面分层、弹性信息卡、扫光、推近失焦、图标与标语；适合正式信息收束 | `studies/ending-ae/Entry.tsx` + `render.mjs` |
| 片尾参考对比 | 12 秒 / 60 | 左右并排比较参考片尾与新版；仅在自备 `sourceVideo` 时生成 | 同上，`Comparison` |
| 投锚＋实体片尾 | 20 秒 / 30，1920×1080 | 6 秒金属锚入水、链条、水花与水下镜头，接 14 秒实体信息卡与品牌片尾 | `studies/ending-ocean/scene.py`、`Textures.tsx`、`prepare.mjs`、`render.mjs` |
| 单独投锚段落 | 6 秒 / 30 | 从上述完整成片切出，可用于片头或象征性插入镜头 | `ending-ocean/render.mjs` 同时输出 |

```sh
# 光影片尾：无需参考视频即可生成新版；参考对比为可选。
npm run render:ending:ae -- --review-only
npm run render:ending:ae

# 历史三维片尾：先由 Blender 输出 180 帧，再合成。
blender --background --python studies/ending-3d/scene.py -- --animation
npm run render:ending:3d

# 海洋组合：先生成中文文字贴图，后渲染/编码。
npm run prepare:ending:ocean
npm run render:ending:ocean
# 已有完整帧序列时，可跳过三维渲染。
node studies/ending-ocean/render.mjs --encode-only
```

海洋工程时间线为 60 fps，渲染奇数帧后编码为 30 fps。水面用 Ocean 波浪修改器，水花与气泡是定向制作的几何及粒子轨迹，不是流体求解缓存。`opening-view.py` 仅调整已保存 Blender 工程的初始视图，不生成新片段。三维研究依赖 Blender，浏览器动态图形依赖 Remotion，两者不能互相替代命令。
