# Security and media boundary

This portfolio edition contains no credentials, user recordings, analytics, private API calls, competition documents, or third-party skill bundles. The UI shown in code and screenshots is synthetic product-demo content.

Production-study source code is also included. Those studies accept user-supplied native captures and optional ending metadata at runtime; these inputs are not distributed with the repository. See `docs/素材与运行.md`. Generated manifests and bundles may contain local source paths or copied media and must remain local unless separately reviewed.

Generated video, audio, environment files, and render outputs are ignored by Git. Please report security concerns without attaching private media.
